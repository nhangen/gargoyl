Word guide: A coordinator report is what your Darkbloom account says about a provider — account-side reporting, not an independent observation of that remote machine. Heartbeat: recent = within 2 minutes of now; older = older than that (the age is shown beside it); unknown = no usable heartbeat time, or one ahead of this Mac’s clock. Report: current = account read at most 2 minutes old, session connected and the account reader running; stale = any other read (older, disconnected, or reader stopped); unknown = the read time is ahead of this Mac’s clock, so its freshness cannot be judged. A provider ID is the opaque identifier your account assigns to a machine; it is not a host name. This Mac is the only row with direct local collector observations; other rows carry coordinator reports, plus live telemetry only where a row is marked Tailscale peer. What changes (mock notes, not part of the app)

  1. Toolbar (NSToolbar): one row instead of 11 buttons in 4 rows. Account is a menu item that shows the connection state and enables only valid actions (menu validation). Local aliases… is its own item because aliases are local, not account data. Labels keep "local": Export local report…, Restart local provider…. Restart is a standard button set apart at the trailing edge; its confirmation sheet does the safety work. NSToolbar overflow handles narrow windows.
  2. Monitor: a label plus one action. The label states only what the app knows (it started or stopped the job), never "running" as a health claim.
  3. Messages from native actions go to a status strip under the toolbar with a Clear button (native, so it survives the 30-second page refresh; the web view runs no scripts). Warnings computed from the data (disconnected, partial) stay in the page and can't be dismissed.
  4. Table: full provider IDs stay in every row (selectable). The account summary shows report freshness (current / stale / unknown) with its glyph. The coordinator column shows each provider’s reported status as text, outlined when adverse. Heartbeat shows the full time, recency and age at read, or the specific reason when there is none. Label source stays visible for aliases.
  5. Coverage: the “This Mac” badge marks the verified association. One note below the table explains the coverage limits that apply to the other providers. The production Fleet management view also lists local process evidence, history and the operator workflow for the matched Mac.
  6. Duplicate labels get Set alias…, a gargoyl-view:// link the app intercepts to open the alias sheet with that provider preselected.
  7. This Mac becomes a facts grid with source and time per observation and keeps the alias and association honesty text. No new navigation route.
  8. Narrow windows (the app's minimum width is 390 px) keep the sideways-scroll hint.
