developer docs

Build on Gargoyl.

Install it, read the v1 contract, and see how collection, the dashboard and repairs fit together. Everything here runs locally.

Quick start

1

Get the code

Clone the repository, make a virtual environment, and install the package into it.

2

Start the local monitor

The monitor reads one daemon-state file you name and serves a viewer on loopback only. Open http://127.0.0.1:8765/, check it from a second terminal, and stop it with Ctrl-C.

3

Or build the Mac app Optional

Prefer a window to a terminal? Build the native app from the same checkout. It connects read-only.

Privacy is part of the schema.

Prompts, completions, credentials, raw logs, customer identifiers, IP addresses and model names are rejected by the v1 contract. No setting turns that off.
