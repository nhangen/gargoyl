Principles

Clear telemetry, no guesswork

Each host tracks its source, freshness window, and telemetry state: observed, stale, unknown, or blocked. Gargoyl flags the real issue instead of smoothing over an outage, so you know exactly which host needs attention.

Privacy by design

Host telemetry stays aggregate and private. A host only sends basic counters like request numbers and uptime tied to an opaque ID. Prompts, completions, API keys, raw logs, customer identifiers, IP addresses, and model names are rejected by the schema, and no setting turns that off.

Fix problems with one click In development

Gargoyl helps you restart stuck host daemons or network connections safely. Each repair checks its target first and waits for your confirmation, so nothing changes on your machine without your permission.
