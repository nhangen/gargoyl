See which Darkbloom host reports to trust, and which to recheck.

Gargoyl reads each host's routing, model and verification reports and shows the evidence behind every state, so a stale or blocked reading tells you exactly what to look at. Repairs you approve host by host are in development.

Principles

Evidence over assumptions

Each field keeps its source, timestamp, freshness window and state: observed, stale, unknown, or blocked. A field reads unknown when evidence is missing or sources disagree, so you see what to recheck instead of a smoothed verdict.

Privacy by design

A host can only send the small set of aggregate fields on an allowlist, each one tied to a short ID you can treat as a label. Prompts, completions, credentials, raw logs, names, IPs, hostnames and model names are rejected by the schema itself.

Repairs under your control In development

Repairs draw from a short, approved action list. Each repair checks its target first, touches one host, and waits for your confirmation. It has run in simulation so far, and live-host support is still ahead.

We are building this now.

Darkbloom is the first integration. The telemetry schema, privacy checks and evidence dashboard are in progress; host enrollment and live-host validation come next.
